# researcher, in this project

<!-- covers: none -->

The role itself is shared and lives outside this repository, at `~/.claude/agents/researcher.md`.
If you have cloned this project that file will not be there, and nothing here depends
on it: what follows is a description of THIS repository's commands, paths and hazards,
which is useful on its own. Where both exist, this file wins.

What is shipped is a macOS application, to the public, through a Homebrew cask and a Sparkle appcast.

Research goes at the repository root.

This project is GPL-3.0-or-later, which governs what may be linked into it - a dependency's licence is a shipping question here rather than a preference. Apple's notarization and FSKit rules are platform constraints that change without this repository being told, so they are established from Apple's own documentation at the version being shipped rather than from memory.
