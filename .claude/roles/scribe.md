# scribe, in this project

<!-- covers: none -->

The role itself is shared and lives outside this repository, at `~/.claude/agents/scribe.md`.
If you have cloned this project that file will not be there, and nothing here depends
on it: what follows is a description of THIS repository's commands, paths and hazards,
which is useful on its own. Where both exist, this file wins.

Documents live at the repository root - `BUILDING.md`, `MEASUREMENTS.md`,
`nfs-stall.md` and the standard public set among them. There is no `docs/` directory.

There is no project ownership map, so `~/.claude/doc-owners.json` is the whole of it.

This repository is **public**, and carries an unusually large protected set for its size:
README, CONTRIBUTING, CODE_OF_CONDUCT, PRIVACY and SECURITY are all present and all read
by strangers. Draft changes to them; do not edit them.
