lukotta

Open BitLocker and Linux drives on macOS. Type the drive’s password and it appears in Finder, readable and writable, like any other disk.

Download Source

Apple Silicon · macOS 15 Sequoia or later · free and open source

What it does

  • BitLocker drives, with the password or a 48-digit recovery key.
  • Windows NTFS drives, including ones Windows left hibernated or not shut down properly.
  • LUKS drives from Linux, both LUKS1 and LUKS2.
  • LVM inside LUKS, as Ubuntu, Debian, Mint and Fedora set it up. Several volumes on one drive all unlock together.
  • Mounts read and write, not read-only.
  • An administrator password once, when the background helper is set up. Not again, and never to eject.
  • Nothing to install first, and nothing downloaded at first run — the engine ships inside the app.

One-time setup

macOS refuses raw access to an encrypted disk to every process, including ones running as root, unless the app holds Full Disk Access. An administrator password alone is not enough. Add Lukotta in Privacy & Security → Full Disk Access, then reopen it. The app explains this on first run and opens the right page of System Settings.

Known limitation

The drive appears under Locations in Finder, but macOS classifies it as a network volume rather than a local disk. The drive is unlocked inside a small Linux virtual machine and handed to Finder over a local network connection, and macOS offers no way to present that as a local disk. It reads, writes and ejects like any other drive.

Open source

Lukotta is GPL-3.0-or-later. It is built on anylinuxfs, which does the mounting. Complete corresponding source for every component — including the Linux kernel and every package in the embedded image — is published with each release.
