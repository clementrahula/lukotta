- The first public release.
- Lukotta can sit in the menu bar, offering to eject each open drive. It stays
  there when the app is quit with a drive still open, so a drive is never left
  with nothing to eject it by, and it can be hidden from its own menu.
- Unlocking a drive that needs an administrator asks for the password once,
  under the app's own name. The background helper is set up before the drive is
  opened rather than after, so every later unlock needs nothing at all.
- A drive that stopped responding, or a file served after a relaunch, keeps its
  own name in the list. A drive that is mounted is never taken out of the list
  by a scan that missed it.
- A saved passphrase the Keychain already holds is written over rather than
  refused, so a key saved by an earlier version keeps working.
- An update that installs a version this Mac cannot start puts the previous one
  back on its own.
