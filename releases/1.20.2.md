- The background helper is set up once, with one password, and never asks
  again. A later version of it replaces the running one by itself, so a fix to
  the helper arrives with an ordinary update instead of another password.
- A drive that needs an administrator no longer falls back to a password panel
  named after a scripting tool when the helper is set up. If the helper cannot
  open the drive, it says so instead of quietly going round it.
